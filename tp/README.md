# TP — Prompt engineering (J1 matin)

Le pendant pratique des fondations du J1 :
[`TP_Prompt_Engineering_Dev_DevOps.md`](TP_Prompt_Engineering_Dev_DevOps.md) — treize techniques,
du prompt naïf à ReAct, chacune appliquée à un cas Dev ou DevOps de l'application fil rouge
(Dockerfile, sondes Kubernetes, Conventional Commits, dimensionnement, revue de code, post-mortem,
migration de base, diagnostic SRE…).

- **Rien à installer** : les prompts se copient dans l'application Claude (claude.ai ou Desktop),
  une nouvelle conversation par exercice. Aucune clé d'API, aucun code à exécuter.
- **Comparer deux modèles** avec le sélecteur de modèle quand l'exercice le demande : un
  désaccord est un signal de revue humaine.
- **Données synthétiques uniquement** (R1) : un prompt est une donnée sortante.
- **Livrable** : une bibliothèque de cinq prompts structurés par binôme — la matière première des
  commandes et des skills de J2.
